gistfold

Every flag, subcommand, and exit code. Same examples as the README.

Synopsis

gistfold [options] [dir]
Tip: gistfold --help prints this text in the terminal. gistfold --version prints 1.0.0.

Flags and arguments

Flag / argumentMeaning
-h, --helpPrint detailed usage and exit 0.
-v, --versionPrint 1.0.0 and exit 0.
dirDirectory to scan. Defaults to the current working directory. Only top-level files count.

Exit codes

CodeMeaning
0Folder is OK. JSON status is "OK".
1Folder is missing a required file. JSON status is "FAIL".

Configuration

No configuration file. The check is fixed: README.md (any case), a filename matching /^example\./i, and at least one other regular file as the implementation.

Worked examples

Success path

The folder contains README.md, example.js, and index.js.

gistfold ./demo
{"ok":true,"status":"OK","hasReadme":true,"hasExample":true,"hasImpl":true}

The printed object also includes dir (absolute path) and files (top-level filenames).

Failure path

An empty directory fails every check.

mkdir empty && gistfold ./empty ; echo exit:$?
{"ok":false,"status":"FAIL","hasReadme":false,"hasExample":false,"hasImpl":false}

Exit code is 1.
